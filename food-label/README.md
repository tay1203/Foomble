# Foomble frontend

React 19, TypeScript, Vite, and Tailwind CSS frontend for Foomble.

See the [project README](../README.md) for configuration, local development,
backend setup, and deployment instructions.

- [Open Foomble](https://food-label-a679e.web.app)
- [GitHub repository](https://github.com/tay1203/Foomble)

Run from the repository root:

```bash
npm --prefix food-label ci
npm --prefix food-label run dev
```

Configure `food-label/.env.local` using `.env.example` and run the Firebase
emulators in a separate terminal with `npm run emulators` for local API calls.
